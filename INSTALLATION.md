# WP Roles & Permissions - Installation Guide

## Installation

### Method 1: Manual Installation

1. Download the plugin files
2. Upload the `wp-roles-permissions` directory to the `/wp-content/plugins/` directory
3. Activate the plugin through the 'Plugins' menu in WordPress
4. Navigate to 'Roles & Permissions' in the WordPress admin menu to start managing roles

### Method 2: Via WordPress Admin

1. Go to Plugins > Add New in your WordPress admin
2. Upload the plugin zip file
3. Click 'Install Now'
4. Activate the plugin

## Initial Setup

After activation:

1. The plugin automatically adds the necessary capabilities to the Administrator role
2. No additional configuration is required - the plugin is ready to use
3. Access the plugin via the 'Roles & Permissions' menu in the WordPress admin sidebar

## Requirements

- WordPress 5.0 or higher
- PHP 7.0 or higher
- Administrator access to manage roles and permissions

## Features Activated

Once installed, the plugin provides:

- Custom role creation and management interface
- User role assignment functionality
- Post/page access restriction based on roles
- Automatic permission checking on the frontend
- Role-based content filtering in queries

## Next Steps

After installation, you can:

1. **Create Custom Roles**: Go to Roles & Permissions > Manage Roles
2. **Assign Roles to Users**: Go to Roles & Permissions > Assign User Roles
3. **Restrict Content**: Edit any post or page and use the "Content Access Restrictions" meta box
